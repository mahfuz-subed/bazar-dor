Project name : Bazar Dor

Short description: It is a grocery price taking website that gives update about items of need.

Technologies used : Next.js, Typescript, Tailwind CSS, MongoDB.

5 key features of the project:
1: Has a marquee for all the products. 2. People can log in to see the product details.
3.They can update their user info.
4.Responsive UI.
5.Has sorting feature for products.
